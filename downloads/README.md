# Sifa 0.1.0 — Windows Engine Preview

[Скачать ZIP для Windows x64](./Sifa-0.1.0-windows-x64-preview.zip?raw=true)

1. Скачайте архив по ссылке выше. Если открылась страница файла, нажмите **Download raw file**.
2. Распакуйте архив и запустите `Sifa/Sifa.exe`.
3. Панель откроется в браузере. Консоль должна оставаться открытой; `Ctrl+C` завершает приложение.

**Это экспериментальный прототип. Android и Standoff 2 пока не запускаются.**
Реализованы тестовое x86-ядро, панель управления, профили и лаборатория мыши.
Windows executable кросс-компилирован; запуск на настоящем Windows-ПК ещё не проверен.
Подробная документация и лицензия JSON-библиотеки включены в архив.

Контрольная сумма SHA-256 находится в соседнем файле `.zip.sha256`.
