# Sifa 0.1.0: Windows-сборка отозвана

**Не запускайте ранее скачанный Sifa.exe и не добавляйте его в исключения антивируса.**

30 октября 2026 года пользователь сообщил о блокировке ZIP при скачивании
Microsoft Defender. На предоставленном скриншоте указан детект
`Trojan:Win32/Sabsik.TE.A!ml`, критический, со статусом «Активно».

Причина обнаружения пока не установлена. Ложное срабатывание не подтверждено.
Сборка не имеет Authenticode-подписи и не проходила проверку Defender на машине сборки.
Она удалена из текущей версии этой ветки до завершения расследования.

Сверка подтвердила: опубликованный ZIP совпадал с локальным архивом,
а EXE внутри него — с собранным EXE. Проверены происхождение компилятора и
исходный код; эти проверки не заменяют анализ Windows executable антивирусом.

Идентификаторы проверяемого образца:

- SHA-256 Sifa.exe: `0824f6ec56eabcfbc8533bda20b5b3de21c68c2280958650a83e5f40dd99f1eb`
- SHA-256 ZIP: `0bf7be75d9a5ad028c8babd0208ba3e960c6242e0318613f2daf36b9c82cdb5d`

Не отключайте Defender, не выбирайте «Разрешить» и не восстанавливайте файл из карантина.
Используйте предложенное Defender удаление или карантин. Для уточнения нужны
детали обнаружения («Затронутые элементы») и заключение производителя антивируса.

Удаление из текущей ветки не удаляет прежние коммиты Git, кэшированные ответы
или уже скачанные копии. Контрольные образцы сохранены локально для расследования;
изменённых сборок для обхода детекта не выпускалось.

## Копия в main

Первоначальная публикация была объединена с main. Отзыв из отдельной ветки
скачивания не изменил main автоматически. Этот коммит удаляет ZIP и его
контрольную сумму из текущего дерева main, сохраняя историю Git. Уже скачанные
архивы не меняются: используйте карантин или удаление, предложенные Defender.
